A short poem about agency: the power to ask and to be given.

Entry for the [make.fun bounty "The poem about permission"](https://make.fun/bounty/the-poem-about-permission-20261121-0235).

## Run

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

Writes the poem to `output/entry.txt` (UTF-8, 166 characters, deterministic).

## Poem

> I handed my keys to a voice with no hands.
> It opened every door I named, then set them down
> and waited.
> The power was never the opening.
> It was asking for them back.
